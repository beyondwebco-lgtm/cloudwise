# CloudWize Brand Identity & Design System

## Core Positioning
Enterprise Blue × Premium Minimalism × Modern Technology

## Color Palette
```css
:root {
  --navy: #071B38;           /* Hero, footer, dark sections */
  --corporate-blue: #123B73; /* Headers, secondary surfaces */
  --primary-blue: #2563EB;   /* Buttons, links, accents */
  --sky-blue: #60A5FA;       /* Highlights, subtle effects */
  --ice-blue: #EFF6FF;       /* Light section backgrounds */
  --background: #FFFFFF;     /* Cards, whitespace */
  --surface: #F8FAFC;        /* Secondary background */
  --text-primary: #0F172A;   /* Primary dark slate text */
  --text-secondary: #475569; /* Secondary slate text */
  --border: #DBE5F0;         /* Subtle card & divider borders */
}
```

## Typography
- **Headings**: Manrope (weights 600, 700, 800) with system fallbacks
- **Body**: Inter (weights 400, 500, 600) with system fallbacks
- **Tagline**: *Technology. Transformation. Talent. Trust.*

## Logo System
- **Emblem**: Intertwining cloud silhouette with three rising royal blue circuit nodes representing technology modernization, data flow, and connected advisory.
- **Wordmark**: "Cloud" in Midnight Navy `#071B38` + "Wize" in Royal Blue `#2563EB`.
- **Sub-tag**: "CONSULTING SERVICES" in spaced tracking uppercase.
